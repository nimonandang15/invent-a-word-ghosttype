One invented English word with a one-line definition of at most 140 characters. A judge model compares the entries two at a time and the word it would most want to see in a dictionary wins.

## The word

> ghosttype — The typing dots that appear, linger, then vanish without a message ever arriving.

93 characters, 95 bytes, one line. Everyone has watched the three typing dots appear, linger, and then vanish — no message ever arrives. English has "ghosting" for a person who disappears, but no word for the dots themselves doing it. "ghosttype" names the vanishing act, not the person: the dots are the ghost, typing is what they pretend to do, and the silence afterwards is the whole point. It is built from two words every phone user already knows, so it is sayable, spellable, and memorable.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry to `/output/entry.txt` (95 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–140-character gate.
